# Delivery conventions (template)

How the main session publishes a report at gate four.

- Document tool and CLI:
- Before editing an existing document: fetch the live version, locate by content not by cached ids
- Data tables: embedded spreadsheet block vs native table — which, and how to fill it
- Writing into a shared sheet: read the header row first, address columns by name, append new columns on the right only
- Encoding and file-format traps your audience hits (e.g. CSV BOM for Excel, spreadsheet cells starting with `=`)
