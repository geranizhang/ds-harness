# Analytic stances (template)

Team choices that are *decisions*, not universal discipline. The core carries the mechanisms (approval files, validators); the stance decides the default. Each entry: the stance, one sentence of why, when it was set.

| Stance | Default | Why |
|---|---|---|
| sampling | full data; sample only on explicit approval | precision loss is certain, I/O savings are not |
| regions in analysis | merge across regions; per-region only for internal checks or on request | |
| impact estimates | point estimate / upper bound (choose) | risk control vs measurement |
| multi-region execution | all default regions in parallel | |
| new populations | never invented by the analyst | |
