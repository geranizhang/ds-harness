# Settled findings (template)

What past analyses concluded, so new briefs build on them instead of re-deriving. **The workflow appends here** at §5 (verdicts) and §6 (delivery). One entry per finding:

```
## <one-sentence finding>
- date: YYYY-MM-DD · confidence: high · topic: <project>/<topic>
- criterion: <how it was judged> · explained share: <X% of the gap>
- evidence: <deliverable + version>
- superseded by: — (fill when a later finding overturns it; never delete)
```

Dated evidence from the metric dictionary belongs here, not in `knowledge/metrics.md`.
