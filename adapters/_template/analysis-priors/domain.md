# Domain research (template)

What a new analyst must know about how this product or system works before writing a hypothesis. Mechanisms, not metrics.

## How the system works

e.g. the recommendation funnel and what each stage decides; the order lifecycle; where supply and demand meet.

## Where questions usually land

Which stage or mechanism a class of question usually points at ("penetration questions are usually a ranking-stage question").

## Reference documents

Links to the team's methodology notes and upstream design documents (title, where, one line on what it settles).
